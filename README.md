# QR Medikal (Demo)

Bu depo, QR Medikal HTML demosunu Capacitor ile Android APK olarak derlemek için hazırlanmıştır.

## APK oluşturma
GitHub deposuna bu klasörün **içindeki dosyaları** yükleyin (ZIP dosyasını tek başına değil). `main` dalına commit edildiğinde GitHub Actions otomatik çalışır. Ayrıca Actions sekmesinden `Build QR Medikal Android APK` iş akışı manuel başlatılabilir. Başarılı çalışmanın Artifacts bölümünden `QR-Medikal-debug-APK` indirilebilir.

## Önemli
- Bu yalnızca demo prototipidir. İçindeki hasta kayıtları ve giriş bilgileri örnektir.
- Gerçek hasta verisi, gerçek kimlik numarası veya gerçek sağlık bilgisi eklemeyin.
- Bu paket, gerçek sağlık sistemi/personel doğrulaması veya resmi kurum bağlantısı sağlamaz.
- Kamera/QR tarama özelliği Android WebView üzerinde cihaz ve sürüme bağlı olabilir; bu ilk APK'da garanti edilmez.
- Bu debug APK test amaçlıdır; Play Store yayını için ayrıca imzalama ve mağaza hazırlığı gerekir.
